# Otso live forecasts

Daily PM2.5 forecasts of Otso (Foehn-CAMS, 0.4°), 12 h to 120 h ahead, the last 7 days. This branch is rewritten every day (one commit). Page: https://ammarkheder.com/Otso/ . Code: the `main` branch of this repository.

Otso 1.2 is a research forecast (Foehn-CAMS, 0.4 degrees, trained on the CAMS analyses of 2017-2022, fine-tuned on the live inputs of January-August 2026, run on live inputs since October 2026). It is not an official product and does not replace the air-quality forecasts and alerts of your country.
